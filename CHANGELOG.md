# Changelog

All notable released versions of APS Conecta Gestión, newest first. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow
[Semantic Versioning](https://semver.org/).

This file is deliberately thin — it records **tagged releases only**. The running narrative of
what's done, in progress, and planned lives in [`ROADMAP.md`](ROADMAP.md); per-epic detail lives in
[`docs/planning/epics.md`](docs/planning/epics.md). This file links there rather than restating it.

  live collaborative editing. See [`ROADMAP.md`](ROADMAP.md).
- **Not yet released.** `v1.0.0` will be tagged once the human browser-acceptance run
  ([`docs/ACCEPTANCE-EDITING.md`](docs/ACCEPTANCE-EDITING.md)) passes — its browser-only checks are
  not yet run, so the version stays unreleased until then.
